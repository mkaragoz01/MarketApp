# MarketApp

MarketApp, ASP.NET Core ile geliştirilmiş örnek bir web uygulamasıdır.

## Özellikler

* Kullanıcı giriş sistemi
* Veritabanı entegrasyonu
* REST API desteği
* Modern ve responsive arayüz

## Kurulum

Projeyi klonlayın:

```bash
git clone https://github.com/kullaniciadi/MarketApp.git
```

Proje klasörüne geçin:

```bash
cd MarketApp
```

Bağımlılıkları yükleyin ve uygulamayı çalıştırın:

```bash
dotnet restore
dotnet run
```

## Teknolojiler

* ASP.NET Core
* Entity Framework Core
* SQL Server
* Bootstrap
